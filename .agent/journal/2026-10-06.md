## Designer how-to (what this session learned)

- **Codex designer.** In the task worktree: `herdr pane split w2:p1 --direction down --cwd <wt>
  --no-focus`, rename the pane to the task ID, then `herdr agent start <name> --kind codex --pane
  <p> --timeout 120000 -- -m gpt-6-astra -c model_reasoning_effort=high -c
  'sandbox_mode="workspace-write"'` and brief it with `herdr agent prompt` (it reads
  `.agent/roles/designer.md` itself). On its first launch today Codex self-updated and exited;
  restart it. Resume a session with `-- resume <session-id> -m gpt-6-astra ...`. Codex asks the owner
  to approve each browser run, and a `git add`/`git commit`, because the worktree's index lives
  outside its sandbox.
- **Usage.** Codex's five-hour allowance ran out mid-task (reset 14:23; next 19:25). OpenCode on
  `openai/gpt-6-astra` uses a separate account; the owner allowed it once as a stand-in, and it ran
  out too. Launch: `--env "OPENCODE_CONFIG_CONTENT=<json>"` on the pane split (edits allowed; web
  fetch and push denied; verify, git bookkeeping and `herdr agent prompt lead` allowed; every other
  shell command asks), then `herdr agent start <name> --kind opencode --pane <p> -- --model
  openai/gpt-6-astra [--session <id>]`. Its interactive mode takes no effort setting.
- **Handing over.** When a designer stops mid-task, write a handover note above the Handoff naming
  the uncommitted files and what the next agent finishes, commit only the note, close the pane,
  and brief the next agent to finish rather than restart.
- **Review.** `dispatch.sh <ID> --role reviewer` needs `.agent/runs/<ID>/builder/meta.json` with
  the real CLI (`{"cli":"opencode",...}`) for a hand-opened designer, or it picks the designer's own
  family; it also checks `depends_on` statuses in the kit worktree's task files. Resume the same
  reviewer for the re-review with `--resume --message "..."`.
- **Walking fixtures.** `python3 -m http.server 8712 --bind 127.0.0.1` from the worktree's
  `docs/design`, Chrome at 1440×900 on
  `http://127.0.0.1:8712/visual-directions/frost/back-office/<page>.html?state=<state>`; stop it after.
- **Watching.** A queued Codex question keeps `herdr agent get` at `blocked`, so `herdr agent wait
  --until blocked` returns at once; watch for a new commit or a new prompt in `herdr pane read`.
