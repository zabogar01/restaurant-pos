## One-shot flags

### Claude Code — `claude -p`

| Need | Flag | Notes |
|---|---|---|
| One-shot | `-p`, `--print` | Skips the workspace trust dialog. |
| Model | `--model <alias\|full name>` | Aliases `opus`, `sonnet`, `haiku`, `fable`, or a full id such as `claude-opus-5-5`. |
| Effort | `--effort <low\|medium\|high\|xhigh\|max>` | |
| Role / system prompt | `--append-system-prompt <text>`; `--system-prompt <text>` replaces the default | `--bare` help text also names `--system-prompt-file` / `--append-system-prompt-file`. `--system-prompt-snapshot on` (default) records the prompt on the first request and reuses it on resume even if a later launch passes different text. |
| Resume | `-r`, `--resume <session-id>`; `-c`, `--continue` (latest in cwd); `--fork-session`; `--session-id <uuid>` to pre-assign an id | |
| Output format | `--output-format text\|json\|stream-json` | `json` returns `session_id`, `num_turns`, `is_error`, `result`. |
| Max turns | `--max-turns <n>` | **Not listed in `--help`**, but accepted: `claude -p --model haiku --max-turns 1 --output-format json "say hi"` returned `subtype: success`, `num_turns: 1`. Treat as undocumented and re-test after upgrades. |
| Spend cap | `--max-budget-usd <amount>` | `--print` only. |
| Read-only | No sandbox flag. Use `--permission-mode plan`, or restrict tools with `--tools "Read,Grep,Glob"` / `--disallowedTools`. `--restricted` removes Bash and other code-running tools. | |
| Permissions in one-shot | `--permission-mode acceptEdits\|auto\|bypassPermissions\|manual\|dontAsk\|plan`; `--permission-prompts none` denies anything that would prompt | Needed for unattended builders. |
| Settings isolation | `--setting-sources user,project,local`; `--settings <file-or-json>`; `--safe-mode`; `--bare` | See the caveman finding below. |

## Findings for later phases

1. **Caveman leaks into one-shot Claude workers.** A bare `claude -p` in a
   scratch dir answered "Yo. Caveman mode live…" — the user-level caveman
   plugin's SessionStart hook loads into every Claude launch. The kit wants
   caveman off for architect, designer and reviewer. KIT-002/KIT-004 must
   decide how (e.g. `--setting-sources project`, a `--settings` override, or an
   explicit role-prompt instruction) and test it.
2. **No turn cap for Codex or OpenCode.** Only Claude has one. The stall alert
   is the only runaway guard for OpenAI-side workers.
3. **Codex role injection is prompt-prepend only** (see table).
4. **Herdr pane naming** differs from the playbook sketch (see table).
5. **Codex stdin**: close stdin in `dispatch.sh` or the run may wait on it.
