Purpose

Manage staff: create, assign role, set and reset PIN, deactivate.

Fixed by the PRD

  • Two authenticating roles only: cashier and manager. Kitchen is a non-authenticating classification with no PIN and no permissions. Waiter is deferred — there is no waiter option. FR-A1
  • PINs are six digits and unique across users, so an audited actor is unambiguous. FR-A1, A4, B-13
  • A PIN is never displayed, echoed or recoverable. Set and reset only — no view, no masked reveal. FR-A3, J4, B-11, B-12
  • Deactivating a user or resetting a PIN has an immediate floor consequence and the manager is told so at the moment of the action. FR-B3, AC-32

Not visible in a still

Invalidation happens on the user's next authenticated request at the POS, not instantly. FR-B3
