Back office — 1440 wide

Purpose

See and manage the whole menu; toggle 86 status fast.

Fixed by the PRD

  • The 86 toggle lives here, and its effect must reach the POS within three seconds without a restart. There is no POS-side 86 control. FR-B6, C6, AC-12
  • Menu changes advance a catalog version and can reject in-flight POS commands, so the manager must understand their edit has a floor-side consequence. FR-C7
  • Archiving or changing an item never alters existing order snapshots. FR-C8, B-8
  • Nothing is hard-coded, including demo seed data. The empty state is real. B-24
FR-G13, AC-29

A back-office 86 affecting an item on a leased quick-sale order is rejected while the lease holds, and the rejection names the order.

Ruling C-4 — do not "fix" this

The rejection is correctly quick-sale-only. A table order cannot close with unsent lines (FR-G10), so a table order at settlement has nothing left to fire and an 86 cannot invalidate it. One rejection rule, one trigger condition.

Not visible in a still

  • Propagation to the POS is a two-second poll inside a three-second budget. FR-C6
  • The server independently revalidates availability when a line is added and when an order is sent to the kitchen. FR-C6, E4
