Purpose

Show unresolved print failures and offer a reprint, without ever blocking the floor.

Fixed by the PRD

  • Kitchen and receipt failures are two urgency classes and must never be presented identically. In greyscale that is carried by border weight, size, placement, persistence, and whether clearing needs an explicit action. FR-E6, AC-23
  • Kitchen incidents are persistent until acted on and appear in both clients. Not a toast, never auto-dismissing. FR-E3, AC-33
  • Printing never gates anything. No incident blocks order entry, firing, closing, or navigation. B-15, FR-E3
  • A cancellation ticket is a correction, never a fire. Reprinting one must never read as "send to the kitchen again". B-16, FR-H4
  • UNKNOWN is not FAILED. The operator checks the printer before reprinting. PRD §6

Not visible in a still

  • The incident is application-wide, not tied to an actor session. Resolving it here resolves it in the back office too. FR-E3
  • Dispatching print jobs become UNKNOWN after an application restart. PRD §6
