POS — 1280 × 800

Purpose

Read what was charged, reprint the receipt, and — separately — refund the order.

Ruling C-1

A zero-total order took no money, so there is nothing to return. The Refund action is absent, not disabled — a disabled control invites a manager to hunt for an override that does not exist. FR-G11, H5

Fixed by the PRD

  • Refunds are full-order only. No line selection, no partial amount. B-23, FR-H5
  • The default allocation reproduces each method's effective contribution — amount tendered less change given. A 20.00 cash sale with 4.41 change defaults to 15.59 cash back, not 20.00. FR-H5, AC-25
  • Allocations must add up to the order total exactly. FR-H5
  • Refund needs a manager PIN and a reason, and produces one combined audit entry naming actor and approver. FR-H5, J2, J3, AC-11
  • A reprint shows identical figures. Nothing is recomputed from today's settings. FR-G7, AC-13
  • Refund and void are never the same control. This screen has no void action; POS-03 has no refund action. FR-H1, B-19
  • REFUNDED is terminal. A second refund is rejected. FR-H6, B-10
Designer's call — I-4

Blocked at the moment of the attempt, with the reason named, plus the standing banner on POS-02. FR-H7, B-9

Not visible in a still

  • A failed reprint is the low-urgency print class, never the kitchen emergency. FR-E6, AC-23
  • Cancelling the approval leaves the order untouched. B-20
