Purpose

Pick the thing to work on: an existing open table order, a new table order, or a quick sale.

Fixed by the PRD

  • A table holds at most one open order. Tapping an occupied table opens that order; it never starts a second. FR-D1
  • Quick sale is a variant of the same order model, not a mode and not a fake table. FR-D2, PRODUCT
  • No table transfer, merge, or split. Out of MVP scope.
  • Tables are back-office configuration. No create-table control here. FR-B2
  • A deactivated table disappears here, but cannot be deactivated at all while it holds an open order. FR-C8
Designer's call — I-4

The PRD blocks void and refund against a closed day (FR-H7) but names no POS surface for it. Drawn as a persistent banner here plus a refusal at the moment of the attempt on POS-06, so the cashier learns it before they promise a customer a refund.

Not visible in a still

  • Occupied-table amounts are live server state; the floor refreshes on return from an order. FR-D6
  • The receipt chip is the low-urgency print class and must never be drawn with the weight of the kitchen banner. FR-E6, AC-23
